Claude Code

claude mcp add --transport http finode {{ mcp_url }} --header "Authorization: Bearer {{ token }}"

Claude Desktop

Settings › Developer › Edit config, add this to claude_desktop_config.json and restart Claude. Needs Node.js.

{
  "mcpServers": {
    "finode": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{ mcp_url }}", "--header", "Authorization:${FINODE_AUTH}"],
      "env": { "FINODE_AUTH": "Bearer {{ token }}" }
    }
  }
}

Cursor, VS Code and others

Any client that takes a URL and headers for a remote (HTTP) MCP server.

{
  "mcpServers": {
    "finode": {
      "url": "{{ mcp_url }}",
      "headers": { "Authorization": "Bearer {{ token }}" }
    }
  }
}
